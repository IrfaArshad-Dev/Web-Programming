CSS Position Property

1. Position: Static

Static is the default position of every HTML element. The element follows the normal document flow. Top, right, bottom, and left do not move it.

Static Box
Remember: Static elements cannot be repositioned using top, right, bottom, or left.

2. Position: Relative

Relative positioning moves an element from its original position. Its original space remains reserved.

Relative Box
Remember: The box moves 20px down and 40px right, but its original space remains in the layout.

3. Position: Absolute

An absolutely positioned element is removed from the normal document flow. It is positioned relative to its nearest positioned ancestor.

This is the parent container.

Absolute Box
Remember: The parent has position: relative. Therefore, the absolute box is positioned relative to this parent, not the whole page.

4. Position: Fixed

A fixed element is generally positioned relative to the browser viewport and stays in the same place while the page scrolls.

Scroll the page to see the pink box stay visible.

Example: Fixed positioning is useful for floating help buttons, chat buttons, or persistent navigation controls.

5. Position: Sticky

Sticky positioning behaves like normal positioning until the element reaches a specified scrolling offset. It then sticks within its scrolling container.

Sticky Header

Scroll inside this box.

The purple header sticks to the top.

Sticky elements need an offset such as top: 0.

Keep scrolling to observe the effect.

Sticky positioning is useful for section headers.

The header remains within this scrolling container.

Summary

  • Static: Normal document flow.
  • Relative: Moves from its original position.
  • Absolute: Positioned relative to a containing block.
  • Fixed: Usually stays relative to the viewport.
  • Sticky: Switches to a stuck position while scrolling.
